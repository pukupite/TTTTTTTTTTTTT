BUS MANAGEMENT SYSTEM - SUPERVISOR MODULE
Frontend starter using HTML, CSS, JavaScript ES Modules and a simple MVC-inspired structure.

HOW TO RUN
1. Extract this ZIP file.
2. Open the Supervisor_Module folder in Visual Studio Code.
3. Install/enable the Live Server extension if needed.
4. Right-click index.html and choose "Open with Live Server".
5. The browser will open the Supervisor Dashboard.

ARCHITECTURE
- views/: HTML pages (View)
- css/: shared and page-specific styles (View styling)
- js/models/: sample data and data operations (Model)
- js/controllers/: page interactions (Controller)
- js/components/: reusable sidebar and topbar
- js/data/: temporary sample data

IMPORTANT
- This is frontend-only. No backend or database is connected.
- Sample data is stored in JavaScript arrays.
- Some demo changes remain only in memory and reset after refresh.
- Before connecting a database, the Model functions can be updated to use backend API requests.
- This is an MVC-inspired frontend organization, not a full server-side MVC framework.
